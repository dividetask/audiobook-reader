## How to Contribute

### Reporting Bugs

- Use the [GitHub Issues](https://github.com/dividetask/audiobook-reader/issues) page
- Include:
  - Device model and OS version
  - App version
  - Steps to reproduce
  - Expected vs. actual behavior
  - Screenshots or logs if applicable

### Suggesting Features

- Open a [GitHub Issue](https://github.com/dividetask/audiobook-reader/issues) with the "enhancement" label
- Describe the feature, the use case, and how it fits with the project's goals

### Submitting Code

1. Check [open issues](https://github.com/dividetask/audiobook-reader/issues) or create one for what you want to work on
2. Comment on the issue to indicate you're working on it
3. Create a feature branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes
5. Write or update tests as needed
6. Ensure all tests pass
7. Commit with clear messages (see Commit Messages below)
8. Push your branch and open a Pull Request
